# プライバシーポリシー (Privacy Policy)

「SAIN - 参拝・御朱印記録アプリ」（以下、「本アプリ」といいます）は、ユーザーの皆様の個人情報の保護を重要視しています。本アプリが取得する情報、その利用目的、公開される範囲について、以下のとおり定めます。

## 1. 取得する情報と利用目的

本アプリでは、以下の情報を取得・利用します。

### 1-1. アカウント情報
* **メールアドレス、または「Appleでサインイン」で提供される情報:** ログイン（認証）、データのバックアップ、複数端末での利用のため。認証にはAmazon Cognitoを利用しています。

### 1-2. プロフィール情報（ユーザーが入力するもの）
* ニックネーム、自己紹介、プロフィール画像、ヘッダー画像、X（旧Twitter）・InstagramのID、絵馬（願いごと）。
* 利用目的: ランキングやユーザー画面での表示のため。
* **公開範囲:** 上記は、**他の利用者から閲覧できる**情報です（下記「4. 他の利用者に公開される情報」を参照）。「非公開」を選んだ場合は、ランキングや他の利用者の画面にニックネーム等を表示しません。

### 1-3. 参拝の記録
* 参拝した寺社、参拝日、メモ、御朱印の情報（御朱印料など）、御朱印・参拝の写真、参拝したときの天気。
* 利用目的: 参拝・御朱印の記録、カレンダー・目標・御朱印帳・年間のまとめなどの表示、ランキングの集計のため。
* メモと写真は、ご本人のみが閲覧できる領域に保存され、他の利用者には公開されません。

### 1-4. 位置情報
* **アプリを使用中:** 現在地周辺の寺社を地図に表示するため、天気・地方の判定のため。
* **アプリを閉じている間（任意・初期状態はオフ）:** 設定の「近くの寺社のお知らせ」をオンにした場合のみ、寺社の近くに着いたことをお知らせするために、端末の機能（ジオフェンス）で位置を利用します。設定からいつでもオフにでき、iOSの設定で許可を取り消すこともできます。
* **位置情報の取り扱い:** 現在地そのものをサーバーに保存したり、他の利用者に公開したりすることはありません。寺社データの検索のために、現在地を含むおおまかな区画の情報（地図上の区画コード）を問い合わせることがあります。また、お知らせの機能は、端末の中で判定します。
* 地図の「載っていない寺社を提案する」機能を使った場合、ユーザーが選んだ地点の緯度経度が、提案の内容として送信されます。

### 1-5. カメラおよび写真ライブラリ
* 御朱印や参拝の写真、プロフィール画像、御朱印帳の表紙の撮影・選択のため。「まとめ画像」などを写真に保存する場合に、写真ライブラリへの追加の許可を求めます。
* **御朱印に書かれた日付の読み取り:** 御朱印の写真に書かれた日付を、**端末の中の文字認識の機能**で読み取り、参拝日の候補として表示することがあります。読み取りは端末の中だけで行い、そのための写真の送信はしません。参拝日として入れるのは、ユーザーが確認した場合のみです。
* **「写真から探す」（任意）:** この機能を使った場合のみ、写真ライブラリの写真の撮影日時と撮影場所を端末の中で読み取り、寺社の位置と照らし合わせて、参拝した寺社の候補を表示します。写真そのものや正確な撮影場所は送信しません（周辺の寺社の情報を取り寄せるために、約5km四方の区画を表すコードだけを問い合わせます）。候補を参拝の記録として登録するのは、ユーザーが選んだ場合のみです。写真ライブラリへのアクセスは、iOSの設定でいつでも取り消せます。

### 1-6. 課金情報
* プレミアムプランの提供および購入状態の管理のため。決済はAppleを介して行われ、本アプリがクレジットカード情報を直接取得・保持することはありません。購入状態の管理にはRevenueCat社のサービスを利用しています。

### 1-7. お問い合わせ・報告・提案の内容
* 設定の「お問い合わせ」、ユーザーの「報告」、寺社の「追加・訂正の提案」でユーザーが送信した内容。
* 運営者が内容を確認・対応するために利用します。これらは、運営者が管理するGitHubのリポジトリ（非公開）に記録されます。
* お問い合わせでは、ユーザーが選択した場合に限り、アプリの動作の記録（エラーの記録）を添付できます。初期状態では添付しません。
* ユーザーを報告した場合、報告した人（ご本人）の情報は、報告の内容には含めません。

### 1-8. 端末に保存する情報
* 動作を速くするための一時的な保存（寺社データ、お気に入り、設定、未送信の参拝記録など）を、端末の中に保存します。ログアウトまたはアカウント削除の際に、個人に紐づくものは削除します。

## 2. 外部サービス・第三者への提供について

本アプリでは、機能の提供のために以下の外部サービスを利用しています。各社のプライバシーポリシーに基づいてデータが処理されます。

* **AWS (Amazon Web Services):** ユーザー認証、データ（プロフィール・参拝記録・写真）のクラウド保存、問い合わせの受付
* **RevenueCat:** アプリ内課金のステータス管理
* **Apple:** 「Appleでサインイン」、課金（App Store）、地図（Apple Maps）、位置情報から地名への変換
* **気象庁:** 天気・警報の情報の取得（現在地の地域の区分に対する、公開情報の取得です。個人を特定する情報は送信しません）
* **GitHub:** お問い合わせ・報告・提案の内容の記録・管理（運営者のみが閲覧できる非公開のリポジトリ）

本アプリは、**広告の配信や、利用者の行動を追跡する目的の外部サービスを組み込んでいません**。

本アプリは、法令に基づく場合等を除き、ユーザーの同意なしに個人情報を上記以外の第三者に提供することはありません。

## 3. 免責事項

本アプリに掲載されている寺社情報（拝観時間、初穂料など）の正確性には万全を期しておりますが、その内容を保証するものではありません。本アプリの利用によって生じた損害等の一切の責任を負いかねますのでご了承ください。

## 4. 他の利用者に公開される情報

本アプリには、他の利用者と情報を共有する機能（ランキング、ユーザー画面、絵馬）があります。以下の情報は、他の利用者に表示されます。

* ニックネーム、自己紹介、プロフィール画像、ヘッダー画像、X・InstagramのID、絵馬（願いごと）、参拝数・御朱印数、ランキングの順位
* 公開中のユーザーについては、最近の参拝（寺社名と参拝日。御朱印の画像・メモは含みません）

また、寺社ごとの参拝人数（「みんなの参拝」）を、個人が特定できない形で集計して表示します。表示するのは2人以上が参拝した寺社のみで、誰が参拝したかは表示しません。非公開に設定したユーザーの参拝も、人数の集計には含まれます。

「非公開」に設定すると、ランキングの一覧や他の利用者の画面に、ニックネーム等が表示されなくなります（順位と人数の集計には含まれます）。個人が特定される情報を入力しないようご注意ください。

## 5. 不適切な投稿への対応（報告・ブロック）

* 他のユーザーのニックネーム・自己紹介・絵馬などに不適切な内容を見つけた場合は、そのユーザーの画面の「このユーザーを報告」から運営者に報告できます。運営者は報告の内容を確認し、必要に応じて、該当する内容の削除や、利用の制限などの対応を行うことがあります。
* 「このユーザーをブロック」で、そのユーザーをランキング・お気に入りに表示せず、画面も表示しないようにできます。ブロックは、お使いの端末の中だけに保存され、相手には通知されません。設定からいつでも解除できます。
* 公序良俗に反する投稿、他者を誹謗中傷する内容、個人を特定できる情報の投稿は禁止します。

## 6. データの保存期間と削除

* 取得した情報は、サービスの提供に必要な期間、保存します。
* アカウントを削除すると、アカウント、プロフィール、参拝記録、写真などのデータを削除します。削除は、アプリの「設定」→「アカウントの削除」から、いつでも行えます（取り消しはできません）。
* お問い合わせ・報告・提案の記録は、対応が完了するまで保管します。記録の削除をご希望の場合は、下記の連絡先までご連絡ください。内容を確認のうえ、削除します。

## 7. 安全管理

通信は暗号化されて行われます。ユーザーの写真・メモなど、他の利用者に公開しない情報は、ご本人のみが読み書きできるように、アクセスを制限して保存しています。

## 8. 本ポリシーの変更

本ポリシーの内容は、必要に応じて変更することがあります。変更した場合は、このページに掲載し、改定日を更新します。
