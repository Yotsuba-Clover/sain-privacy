# プライバシーポリシー (Privacy Policy)

「SAIN - 参拝・御朱印記録アプリ」（以下、「本アプリ」といいます）は、ユーザーの皆様の個人情報の保護を重要視しています。本アプリが収集する情報とその利用目的について、以下の通り定めます。

## 1. 取得する情報と利用目的
本アプリでは、以下の情報を取得・利用する場合があります。

* **位置情報:** 現在地周辺の寺社をマップ上に表示するため（アプリ使用中のみ取得します）。
* **カメラおよび写真ライブラリ:** 御朱印の画像を撮影、または端末からアップロードしてアプリ内に保存するため。
* **アカウント情報:** データのバックアップや複数端末での同期のため（メールアドレス等）。
* **課金情報:** プレミアムプランの提供および購入状態の管理のため（決済はAppleおよびRevenueCat社を介して安全に行われ、本アプリがクレジットカード情報を直接取得・保持することはありません）。

## 2. 外部サービス・第三者提供について
本アプリでは、インフラ基盤や機能の提供のために以下の外部サービスを利用しており、各社のプライバシーポリシーに基づいてデータが安全に処理されます。

* **AWS (Amazon Web Services):** ユーザー認証およびデータのクラウド保存
* **RevenueCat:** サブスクリプション等のアプリ内課金のステータス管理

本アプリは、法令に基づく場合等を除き、ユーザーの同意なしに個人情報を上記以外の第三者に提供することはありません。

## 3. 免責事項
本アプリに掲載されている寺社情報（拝観時間、初穂料など）の正確性には万全を期しておりますが、その内容を保証するものではありません。本アプリの利用によって生じた損害等の一切の責任を負いかねますのでご了承ください。
